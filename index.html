    SQL 收藏与版本
    草稿自动保存在此浏览器；收藏和历史版本不会上传。
    
  
    使用说明
    从选择练习、编写 SQL 到查看结果的操作指南
    
    
    快速开始
    1. 点击“选择练习题”，按题目、知识点或难度找到要练习的内容。
    2. 在 SQL 编辑器中编写语句；遇到困难可以先看分级提示，或点击“补全代码”查看参考答案。
    3. 等待左下角 SQLite WASM 显示“已就绪”后，点击“运行 SQL”查看结果或错误信息。
    4. 确认查询结果后继续修改、切换下一题；题目进度和草稿会保存在当前浏览器。
    
    
    SQL 工作台
    • 在编辑器中编写 SQL，点击“运行 SQL”查看结果、行数、耗时和错误提示；SQLite WASM 显示“已就绪”后才能执行。
    • “初始化”清空编辑区；“补全代码”载入当前题目的参考 SQL，覆盖现有代码前会先确认。
    • 编辑器支持关键字、表名和字段名补全（Ctrl+空格）、SQL 高亮、括号/引号配对、Tab 缩进和错误行提示。
    • “格式化”整理常见 SQL 子句；“查询并排序”“分组统计”“多表连接”是可直接运行的快捷示例，不会按当前题目判分。
    • 左侧表名可载入查询模板；“最近运行”可重新载入历史语句，也可以清空运行历史。
    
    
    练习与 SQL 管理
    • “选择练习题”支持按题目、知识点和难度筛选；答错的题目可进入“复习错题”，通过后会更新本地进度。
    • “分级提示”逐步给出思路，不会直接展开完整答案；“上一题”“下一题”和“学习路径”用于切换练习。
    • 编辑器可收藏 SQL、保存当前草稿，并自动保留最近 40 个本地版本；在“SQL 库”中可搜索、载入或取消收藏。
    • “执行计划”只分析单条 SELECT/WITH 查询，展示本地 SQLite 计划和通用索引建议，不会执行修改语句或创建索引。
    
    
    查看数据库与表结构
    • 左侧数据库区域显示当前项目和表；点击顶部“表结构”打开侧栏。
    • 侧栏支持“表结构”“ER 图”“数据预览”三个视图；点击字段可插入到 SQL 编辑区，数据预览可查看表数据并复制 INSERT 或 CSV。
    • 侧栏中的“编辑数据表”和“打开 ER 图画布”可直接进入对应工具。
    • “环境说明”可查看本地引擎、数据保存位置和 MySQL 兼容范围；应用不会连接外部数据库。
    
  
    表结构设计器
    • “新建数据表”会把表加入当前项目，并同步到浏览器内的 SQLite 数据库；可添加、编辑和删除字段。
    • 字段支持名称、类型、长度、主键、允许 NULL、默认值和备注；“表关系 / 外键”可维护表之间的关联和基数。
    • 设计器会生成建表 SQL，可复制或点击“执行建表”同步到本地引擎；“导出数据字典”生成 Markdown 说明。
    • “基础结构检查”只提供结构建议，不等同于完整的 1NF、2NF、3NF 证明；“运行自检”用于检查页面功能状态。
    • “启用离线执行”可以暂时关闭或恢复本地 SQL 执行。
    
    
    AI 学习助手
    • 点击“AI 助手”打开对话面板；上方辅导功能和示例问题可在区域内滚动，点“收起功能”可把更多空间留给回答；输入框固定在面板底部。
    • 九项辅导功能分别用于：检查表结构、分级提示、解释 SQL、诊断错误、修正 SQL、生成本题参考 SQL、分析错题、生成举一反三练习和自由提问。
    • 选择功能或点击“试试这样问”后，问题会填入输入框供你修改；点击“发送”才会提交。对话记录可以清空；收起面板可返回工作台。
    • 分级提示按 1 至 3 级逐步提供思路并在本地记录进度。错误诊断要求当前 SQL 与最近一次失败语句一致；自动修正会展示 SQL 差异，只有点击“替换为修正 SQL”才会写回编辑器。
    • AI 生成的个性化练习需要点击“保存为练习”后才加入题库。AI 回答仅供参考，不会自动执行 SQL。
    • 提问会按任务发送所需的 SQL、练习要求、错题统计或表结构；不发送数据库数据行或对话历史。网页直连模式会向 DeepSeek 发送 API Key，网页访问者可以查看该密钥。
    
    
    ER 图设计器
    • “表 ER 图”显示数据表、字段和外键；“概念 ER 图”采用 Chen 记法，以矩形实体、椭圆属性和菱形关系展示结构。
    • 拖动图形可调整位置；概念图中可新建实体、添加或删除属性、编辑表结构、连接实体、编辑或删除关系。双击实体可添加属性，双击关系菱形可修改名称和基数。
    • 可使用工具栏自动布局、放大、缩小或重置缩放；也支持 Ctrl+滚轮缩放。PNG/SVG 导出采用当前图表视图。
    • 表结构和关系会与当前项目关联；布局保存在本机浏览器。
    
    
    导入图片与识别
    在 ER 图设计器选择“导入图片 / OCR”。普通浏览器目前只检测版面候选框，不识别图片文字和关系，生成的实体与字段需手动核对。Android 环境可调用设备 OCR，识别内容仍建议复核。
    
    
    项目与本地数据
    • “项目”可新建和切换工作项目；项目分别保存表结构、ER 图布局和 SQL 草稿。
    • 练习数据、运行记录和学习进度保存在当前浏览器，关闭页面后通常仍可继续使用，不会自动同步到其他设备。
    • “重置练习数据库”恢复练习样例；“重置全部本地数据”会清除本应用保存的数据，执行前会再次确认。
    • 可导入或导出项目 JSON，也可从项目窗口导出当前项目。重要数据建议定期导出备份。
    
    
    手机与网页端操作
    界面会按屏幕宽度调整。手机可用底部导航切换工作台、数据库、ER 图、项目、练习和工具；图表较宽时可在画布内拖动或滚动。网页端可通过顶部按钮进入项目、ER 图、表设计器和表结构。
    
    
    运行环境
    • SQL 使用浏览器中的 SQLite WASM 本地执行，无需单独启动数据库服务；数据保存在当前浏览器。
    • 引擎支持 SQLite 常用查询和部分 MySQL 写法；MySQL 专有语法、函数及行为可能不兼容。
    • “环境说明”会显示本地运行和兼容范围。需要验证 MySQL 专有功能时，请在真实 MySQL 环境中测试。
    
  
      
    引擎说明：SQL 由浏览器内的 SQLite WASM 引擎执行，支持 SQLite 的查询、连接、聚合、事务、视图、索引和子查询等能力，并转换部分常见 MySQL 写法（如建表选项、SHOW TABLES、DESC 和 LIMIT offset,count）。这不是 MySQL 服务，MySQL 专有语法、函数和行为仍可能不兼容；数据库保存在当前浏览器中，不会连接远程数据库。
