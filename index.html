SQL 工作台
  • 编辑区可保持空白供你自行编写 SQL，点击“运行 SQL”查看结果和错误提示。
  • “初始化”清空编辑区；“补全代码”载入当前题目的完整参考 SQL，覆盖现有代码前会先确认。
  • 编辑器会高亮 SQL 关键字、函数、字符串、数字和注释；输入时可补全关键字、表名和字段名，按 Ctrl+空格可查看建议。
  • 输入括号或引号会自动配对；Tab 插入缩进。SQL 执行失败时会标出疑似错误行。
  • “格式化”整理常见 SQL 子句；下方示例按钮可快速载入排序、分组统计和多表连接示例。
  • 左侧数据库表名可载入该表的查询模板；“最近运行”可点选历史语句或清空历史。

    
查看数据库与表结构
  • 左侧列出当前练习数据库及 students、courses、enrollments 示例表。
  • 点击顶部“表结构”打开侧栏；切换表结构/ER 图视图，点字段可插入到 SQL 编辑区。
  • 数据库侧栏可直接打开数据表设计器或 ER 图画布。
  • 表结构刷新按钮目前只提示状态，不会连接外部数据库。

    
表结构设计器
  • “新建数据表”会将空表加入当前项目、左侧列表和表结构面板，并同步到浏览器内的 SQLite 数据库，可立即用 SQL 查询。
  • 可新建字段并编辑字段名、类型、长度、主键、NULL、默认值及备注。
  • 可维护表关系/外键和关系类型；设计器会生成建表 SQL。
  • 可复制 SQL、在本地 SQLite 引擎中试运行、导出数据字典，并运行基础范式检查。
  • “运行自检”可检查页面内置功能状态。

    
ER 图设计器
  • 拖动实体可调整位置；点画布空白处或“新建实体”可添加实体。
  • 实体标题处可创建关系、添加字段或删除实体；删除前会确认，并同时移除关联关系和本地表。
  • 点击关系线选中后可删除；关系标签可用于修改关系类型。
  • 可在实体上添加/删除字段、自动布局，并收起或展开左侧说明。
  • 关系支持 1:1、1:N、N:1、N:N 和自定义标注；多对多建表建议使用中间表。
  • 可将 ER 图导出为 PNG 或 SVG。

    
导入图片与识别
在 ER 图设计器中选择“导入图片 / OCR”。普通浏览器当前只检测版面候选框，不识别图片中的文字或关系；生成的实体候选需要人工核对。Android 环境可调用本地 OCR，但识别结果也建议复核。

    
项目与本地数据
  • “项目”可创建并切换项目；每个项目的表结构和 ER 布局保存在本机浏览器。
  • 练习数据库的数据变更、SQL 编辑内容、最近运行记录和练习进度都会保存在当前浏览器，关闭后再次打开仍可继续。
  • 打开“项目”可选择“重置练习数据库”（保留项目、草稿和进度）或“重置全部本地数据”（清除本应用本机保存内容）。两项操作都会二次确认。
  • 表设计器可导入/导出项目 JSON；项目窗口可导出当前项目。数据不会自动同步到其他设备，也没有连接服务器。

    
手机与网页端操作
页面会根据屏幕宽度调整布局。手机底部导航可快速进入工作台、数据库、ER 图、项目、练习和工具入口；ER 图画布较宽时可在画布内滚动。网页端可直接使用顶部的项目、ER 图、设计表和表结构入口。

    
练习、环境与其他按钮
  • 题目按钮可打开题库；选择题目后会显示要求并清空编辑区，方便自行练习；需要参考答案时点击“补全代码”。
  • 提交 SQL 后会按当前题目要求检查查询结构和结果；已完成题目会保存在本机。示例查询按钮也可载入 SQL。
  • “切换环境”目前只显示当前为练习环境；页面不会连接真实 MySQL。
  • 帮助按钮显示本功能说明；底部导航中的练习入口打开题库，工具入口打开表设计器。

  
  
引擎说明：SQL 由浏览器内的 SQLite WASM 引擎执行，支持 SQLite 的查询、连接、聚合、事务、视图、索引和子查询等能力，并转换部分常见 MySQL 写法（如建表选项、SHOW TABLES、DESC 和 LIMIT offset,count）。这不是 MySQL 服务，MySQL 专有语法、函数和行为仍可能不兼容；数据库保存在当前浏览器中，不会连接远程数据库。
